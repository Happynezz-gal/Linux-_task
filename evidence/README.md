# evidence/

Place your proof-of-work here as you complete each phase.

- `screenshots/` — terminal screenshots (e.g. `id agent007`, `whoami`, permission listings,
  the ownership-change observation in Phase 8).
- `terminal-output/` — redirected/copied command output that isn't already captured by
  `listing1.txt` / `listing2.txt` / `listing3.txt` inside `mission/intel/` itself (e.g.
  `id agent007` output, before/after listings for Phase 5 and Phase 7).

Both subfolders start with a `.gitkeep` placeholder so they can be committed to Git even
while empty.
